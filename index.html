Code Cheat Sheet

Parameter Description Example
border Defines the border width of the table. <table border="1">
cellpadding Defines space inside each cell. <table cellpadding="10">
cellspacing Defines space between table cells. <table cellspacing="5">
width Sets the width of the table. <table width="80%">
height Sets the height of the table. <table height="200px">
align Aligns the table to left, center, or right. <table align="center">
bgcolor Sets the background color of the table. <table bgcolor="lightgray">
colspan Merges columns in a row. <td colspan="2">
rowspan Merges rows in a column. <td rowspan="2">
thead, tbody, tfoot Groups header, body, and footer rows. <thead><tr><th>Title</th></tr></thead>
th Defines a header cell, usually bold. <th>Header</th>
tr Defines a table row. <tr><td>Data</td></tr>
td Defines a table data cell. <td>Content</td>
scope Specifies header association (row or column). <th scope="col">Name</th>
style Adds inline CSS styles. <table style="border: 2px solid black;">
